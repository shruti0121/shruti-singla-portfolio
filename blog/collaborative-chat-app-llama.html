Collaborative Chat App with LLaMA Task Extraction

Shruti Singla – Jan – Apr 2026

Built a full-stack, real-time chat application using vanilla JavaScript, HTML, and CSS on the frontend, with a Node.js/Express backend and MongoDB for persisting user data, chat history, and extracted tasks. Real-time messaging between users was implemented using WebSockets, and RESTful APIs handled authentication, chat management, and conversation history.

The core feature integrates a third-party LLaMA large language model to automatically extract actionable tasks from ordinary conversation — for example, detecting when a message like "can you send me the report by Friday" contains a task, who it's assigned to, and its deadline, without requiring users to manually flag anything.

To make the AI feature practical rather than just a demo, I implemented a rule-based classifier that pre-filters trivial messages (like "ok" or "thanks") before they're sent to the LLaMA API, so the model is only invoked when a message is actually likely to contain a task. I measured the real impact of this optimization by benchmarking the application with and without the classifier across three separate runs: it reduced API calls by 60% and cut average response latency by approximately 59%.

Collaborative Chat App with LLaMA Task Extraction — Full-Stack AI Project. This project combined real-time full-stack development with practical LLM integration, and included measuring and optimizing the performance cost of calling an AI model in a production-style application.
