CPEN 331(Operating Systems)

Shruti Singla – 21 April 2026

CPEN 331 (Operating Systems) explored the fundamental concepts and implementation of modern operating systems through hands-on kernel development using OS/161. The course consisted of six major projects that progressively developed core operating system functionality while emphasizing concepts such as conditional variables, semaphores, file_descripters, virtual memory, and many syscalls including sys_fork and sys_execv.

Projects involved implementing essential kernel components including synchronization primitives, process management, system calls, file tables, and virtual memory. The course also provided practical experience with kernel-level debugging, source code navigation, and development tools such as GDB, Git, and code browsing utilities while working within a complex operating system codebase.

Operating Systems — UBC Course. The course focused on the design and implementation of operating system kernels, providing practical experience developing core OS infrastructure and understanding the mechanisms behind process management, memory management, concurrency, and system-level software.
