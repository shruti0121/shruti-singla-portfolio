Three-tier-Web-Architecture(AWS)

Shruti Singla – 25 JULY 2026

Designed and deployed a highly available three-tier task management application on AWS using Amazon EC2, Application Load Balancer, Auto Scaling Groups, and Amazon RDS MySQL. Built the infrastructure to support scalable, fault-tolerant, and secure application deployment.

Architected a custom Amazon VPC with public and private subnets, an Internet Gateway, and a NAT Gateway to securely separate application and database tiers. Configured an Application Load Balancer with health checks and Auto Scaling Groups for automatic traffic distribution and instance recovery, while deploying Amazon RDS MySQL in private subnets with Security Groups to restrict database access. Monitored infrastructure health and performance using Amazon CloudWatch.

Three-Tier Task Management Application — AWS Cloud Infrastructure Project. The project focused on designing a secure, scalable, and highly available cloud architecture using AWS networking, compute, load balancing, auto scaling, managed databases, and monitoring services.
