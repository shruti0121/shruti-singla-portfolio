Ricemill Management Platform (AWS)

Shruti Singla – 25 JULY 2026
View on GitHub

Independently designed, built, and deployed a full-stack rice mill management platform on AWS that enables customers to browse products, manage shopping carts, place orders, and view order history through a secure web application. Engineered the solution for production-grade scalability and reliability using containerized services (Docker, Amazon ECS Fargate) and automated CI/CD pipelines.

Architected a distributed, event-driven backend — Amazon SNS and SQS with Dead Letter Queues — decoupling inventory, analytics, and notification services for fault-tolerant processing. Used Amazon DynamoDB for scalable data storage, and implemented RESTful APIs for product, cart, and order management, secured with Amazon Cognito authentication. Automated build, test, and deployment through GitHub Actions CI/CD pipelines for reliable, repeatable releases.

This platform was originally built as a serverless architecture — provisioned with AWS CDK and deploying Lambda, API Gateway, DynamoDB, Cognito, and CloudFront — before I migrated the backend to a containerized Express.js service on ECS Fargate to support more complex, longer-running processing needs.
